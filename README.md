# Evaluación Práctica – Unidad Didáctica: Lenguajes de Marcas

## 📘 Módulo
Lenguajes de Marcas y Sistemas de Gestión de Información (LMSGI)

## 🎯 Objetivos de la unidad
- Comprender los fundamentos de los lenguajes de marcas (HTML, XML) y su papel en la representación e intercambio de información.
- Diseñar e implementar documentos estructurados válidos y bien formados.
- Aplicar hojas de estilo (CSS) y transformaciones (XSLT) sobre documentos de marcado.
- Validar documentos frente a esquemas (DTD, XSD) y detectar errores de sintaxis.
- Utilizar herramientas de edición y validación de lenguajes de marcas.

## 🧩 Contenidos evaluados
1. Estructura y sintaxis de documentos HTML5.
2. Estructura y sintaxis de documentos XML (elementos, atributos, espacios de nombres).
3. Validación de documentos: DTD y XSD.
4. Transformación de documentos XML mediante XSLT.
5. Aplicación de estilos con CSS.
6. Buenas prácticas: semántica, accesibilidad y organización del código.

## 📝 Descripción de la tarea
El alumnado deberá desarrollar un proyecto práctico que incluya:

1. **Documento HTML5** semántico y validado (sin errores en el validador W3C).
2. **Documento XML** propio, bien formado, que modele un caso de uso (por ejemplo: catálogo de productos, biblioteca, agenda, etc.).
3. **Esquema de validación** (DTD o XSD) asociado al documento XML anterior.
4. **Hoja de estilos CSS** aplicada al documento HTML.
5. **Transformación XSLT** que convierta el XML en una vista HTML.
6. **Memoria técnica** explicando las decisiones de diseño tomadas.

## 📂 Estructura de entrega
```
proyecto-lenguajes-marcas/
├── README.md
├── index.html
├── estilos.css
├── datos.xml
├── esquema.xsd (o .dtd)
├── transformacion.xsl
└── memoria.pdf
```

## ✅ Criterios de evaluación

| Criterio | Peso |
|---|---|
| Corrección sintáctica y validez de HTML/XML | 25% |
| Diseño y coherencia del esquema (XSD/DTD) | 20% |
| Correcta aplicación de CSS | 15% |
| Funcionamiento de la transformación XSLT | 20% |
| Calidad de la memoria técnica | 10% |
| Buenas prácticas y organización del código | 10% |

## 🛠️ Herramientas recomendadas
- Editor de código (VS Code, Sublime Text, etc.)
- Validadores: [W3C Markup Validator](https://validator.w3.org/), [XML Validator](https://www.xmlvalidation.com/)
- Navegador con soporte para XSLT
- Procesador XSLT (Saxon, xsltproc)

## 📅 Entrega
- **Formato:** archivo comprimido (.zip) con la estructura indicada.
- **Plazo:** según indicación del docente en el aula virtual.
- **Vía de entrega:** plataforma del centro / repositorio Git (según se indique).

## ℹ️ Notas
- Se penalizará el uso de código no propio sin citar la fuente.
- Los documentos deben poder abrirse y validarse sin dependencias externas no incluidas en la entrega.
